# EULingDiv

This is a repostory holding the code to generate the EULingDiv dataset (https://zenodo.org/records/19676269). It takes the two Eurobarometer surveys on Europeans and their languages from 2012 and 2024, and extracts the number of speakers of the respective languages surveyed according to their native languages (L1) and languages in which they are able to hold a conversation in (L2, L3, L4). For improved interoperatbility, both country ISO-3166 and languages ISO639-3 codes are added to the data.
